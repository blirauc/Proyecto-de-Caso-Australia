# Weather Australia – Análisis y Modelado Predictivo

Proyecto de análisis de datos y machine learning utilizando el dataset WeatherAUS,
con el objetivo de predecir condiciones climáticas a partir de datos históricos.

## Objetivo
Analizar datos meteorológicos históricos y desarrollar modelos predictivos,
aplicando técnicas de limpieza, exploración, feature engineering y evaluación.

## Tecnologías utilizadas
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn
- Jupyter Notebook

##  Estructura del proyecto
- data/raw: datos originales
- data/processed: datos limpioss
- notebooks: análisis paso a paso
- models: modelos entrenados
- docs: informe del proyecto

## Proceso
1. Análisis exploratorio de datos (EDA)
2. Limpieza y preparación de datos
3. Ingeniería de características
4. Entrenamiento de modelos
5. Evaluación con métricas (accuracy, precision, recall)

## Resultados
Se evaluaron distintos modelos de clasificación para identificar el enfoque
más efectivo en la predicción de variables climáticas.
